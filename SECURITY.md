# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability, please email the project leads directly. Do NOT open a public issue.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Security Best Practices

1. Never commit API keys or credentials
2. Never commit real patient data
3. Use encrypted storage for sensitive data
4. Keep dependencies updated
5. Run security audits regularly

## Data Privacy

This project handles sensitive healthcare data. All contributors must:
- Follow GDPR guidelines
- Maintain patient confidentiality
- Report data breaches immediately
- Complete security training

## Incident Response

In case of security incident:
1. Contain the issue immediately
2. Notify project leads
3. Document the incident
4. Follow institutional protocols
5. Update security measures
