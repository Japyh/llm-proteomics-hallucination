# De-identification Procedure

## Process
1. Remove all direct identifiers (names, IDs, dates)
2. Generalize geographic information
3. Replace specific values with categories where appropriate
4. Review by privacy officer

## Verification
- Automated scanning for PII patterns
- Manual review of random sample (10%)
- Independent verification

## Documentation
- All de-identification steps logged
- Mapping tables stored separately (restricted access)
- Audit trail maintained
