# Data Management Plan

## Data Collection
- **Period**: October 2025 - November 2025
- **Volume**: ~600 queries, ~1800 responses
- **Format**: JSON, JSONL, CSV

## Data Storage
- Primary storage: Encrypted institutional server
- Backup: Daily incremental, weekly full
- Retention period: 7 years post-publication

## Data Sharing
- Anonymized datasets: Public repository (Zenodo)
- Code: GitHub (MIT license)
- Raw LLM responses: Available upon reasonable request

## Privacy and Security
- De-identification procedures applied
- Access controls: Role-based
- Audit logs maintained

## Compliance
- HIPAA compliant
- GDPR compliant where applicable
- Institutional data policies followed
