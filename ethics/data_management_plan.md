# Data Management Plan

## Data Lifecycle
1. Collection: Only synthetic or properly anonymized data
2. Processing: Secure computing environment
3. Analysis: Access control and logging
4. Storage: Encrypted storage with backup
5. Sharing: Only with proper agreements
6. Destruction: Secure deletion after retention period

## Retention Policy
- Synthetic data: Permanent (research artifacts)
- Anonymized data: 10 years post-publication
- Raw patient data: Never stored in this repository
