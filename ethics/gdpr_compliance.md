# GDPR Compliance Checklist

## Data Processing Principles
- [ ] Lawfulness, fairness, transparency
- [ ] Purpose limitation
- [ ] Data minimization
- [ ] Accuracy
- [ ] Storage limitation
- [ ] Integrity and confidentiality

## Requirements for Proteomics Data
1. Legal basis for processing established
2. Data subjects informed
3. Consent obtained (if applicable)
4. Data anonymized before analysis
5. Security measures implemented
6. Data retention policy defined
