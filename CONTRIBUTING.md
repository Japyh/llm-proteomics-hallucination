# Contributing to LLM Proteomics Hallucination Study

Thank you for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Development Setup

```bash
git clone https://github.com/olaflaitinen/llm-proteomics-hallucination.git
cd llm-proteomics-hallucination
pip install -r requirements.txt
```

## Testing

Run tests before submitting:
```bash
pytest tests/
```

## Code Style

- Follow PEP 8 for Python code
- Use type hints where applicable
- Add docstrings to all functions

## IRB and Ethics

This study operates under IRB protocol #2025-IRB-1101. All contributions must comply with ethical guidelines.
