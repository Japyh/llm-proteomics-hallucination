# Scripts

Utility scripts for data processing and analysis.

---

## Available Scripts

### check_data_privacy.py

Check data files for potential privacy issues.

```bash
python scripts/check_data_privacy.py data/
```

### generate_report.py

Generate analysis report.

```bash
python scripts/generate_report.py --output report.html
```

---

## Usage

All scripts can be run from project root:

```bash
python scripts/script_name.py [args]
```
